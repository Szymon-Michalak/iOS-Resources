## ⌃⇧Click — Multi-Cursor Editing
Allows you to place multiple cursors across your code. Type once, edit everywhere.

**Shortcut:** `Control (⌃)` + `Shift (⇧)` + Click  
**Also works with:**  
- `⌥` + Click + Drag → Column selection  
- `⌃⇧↑` / `⌃⇧↓` → Keyboard-based column selection  
- `⌥⌘E` → Select Next Occurrence  

**Tips:** 
- Hit `Escape` to exit multi-cursor mode.  
- To remove a cursor: `⌃⇧Click` on it again.

## ⌥→Click — Expand All Groups in Xcode

**Allows you to instantly expand all nested folders in the Project Navigator.** Perfect for large projects where deep folder structures are collapsed by default.

**Shortcut:**  
Hold `Option (⌥)` and click the triangle (▸) next to any group.
**Also Works With:**
- `⌥` + Click triangle again → Collapse all recursively  
- Works on any expandable item in the **Project Navigator**: groups, folders, file hierarchies.

**Tips:**
- Combine with `⇧⌘J` (Reveal in Navigator) to quickly open and expand the current file’s location.
- Doesn't work with keyboard alone — mouse click is required.
